Personal Fitness Activity and Calorie Expenditure Analysis

Project Description

This project uses Exploratory Data Analysis (EDA) to analyze personal fitness activities such as daily steps, calories burned, sleep duration, and exercise minutes.

Objectives

- Understand fitness activity data.
- Perform data cleaning and preprocessing.
- Calculate statistical measurements.
- Analyze fitness activity patterns.
- Visualize data using graphs.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Units Covered

- Unit 1: EDA Fundamentals
- Unit 2: EDA Using Python
- Unit 3: Univariate Analysis

Project Files

- Fitness_Activity_Analysis.ipynb
- fitness_data.csv
- outputs/

How to Run

1. Download the notebook.
2. Open it using Google Colab.
3. Upload the CSV dataset if required.
4. Run the cells in order.

Conclusion

This project demonstrates how Exploratory Data Analysis can be used to understand fitness activity patterns through statistical analysis and data visualization.
